# splitwise-expense-manager-c++

This project aims to develop a console-based Expense Manager in C++ that simplifies splitting and tracking shared expenses, ensuring accurate settlement and transparency among users.

Features:
- Add and view expenses
- Automatic balance calculation
- Debt simplification using priority queues
- Persistent storage using file handling
- Multi-user expense tracking

Data Structures:
- vector
- unordered_map
- priority_queue

Concepts:
- Object Oriented Programming
- Greedy Algorithms
- File I/O
